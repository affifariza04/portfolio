# Portfolio · Affif Ariza Adiwijaya

Live: https://affifariza04.github.io/portfolio/

A one-screen home with three curved entry panels, and one page per discipline, each with its own visual language:

| Page | Feel | |
|---|---|---|
| `/software/` | terminal: dot-matrix display type, green grid, app-window cards | AI and full-stack projects with live demos |
| `/3d/` | game launcher: gradients, tilt cards, live three.js embed | configurator, renders, game asset kits, game UI, CAD |
| `/design/` | editorial agency: light, big type, red accent | 5 product teardowns, UI work, social media, experience |

Static HTML generated by `build/build.py` from `build/content.py` (no framework, no tracking).
SEO: per-page title/description, canonical, Open Graph + Twitter cards, JSON-LD (Person, WebSite, ItemList, Article, BreadcrumbList), `sitemap.xml`, `robots.txt`.

```bash
python build/build.py          # regenerate pages
python -m http.server 8000     # preview
```
