# affif.dev — portfolio

Personal portfolio of **Affif Ariza Adiwijaya**: software & AI engineering, 3D / game assets, and UI/UX, web & social media.

- Zero-dependency static site: `index.html`, `style.css`, `main.js`, images in `assets/work/` (WebP).
- Filterable work grid (Software & AI · 3D & Game · UI/UX, Web & Social), scroll reveal, responsive down to 360 px, respects `prefers-reduced-motion`.

## Run locally
```bash
python -m http.server 5173
```
Open http://localhost:5173

## Deploy
Works as-is on GitHub Pages, Cloudflare Pages or Netlify (no build step; output directory = repo root).
